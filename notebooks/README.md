# Notebooks Directory

This directory contains Jupyter notebooks used for **exploratory data analysis and model development**.

⚠️ **Important:** These notebooks are development artifacts and are **not part of the final reproducible workflow**. They document the exploratory process and model experimentation that informed the final production pipeline.

## Purpose and Scope

These notebooks were used to:
- Explore and understand the merged game data
- Prototype feature engineering approaches
- Experiment with different modeling strategies (Ridge vs. LASSO)
- Develop and test home-field advantage quantification methods
- Validate data quality and identify issues

**The final, production-ready workflow** has been consolidated into a single reproducible script that can be executed via:
```bash
python run_all.py
# OR
make all
```

## Notebooks

### `model_home_field_advantage.ipynb`

**Purpose:** Development and comparison of machine learning models to quantify home-field advantage in college football.

**Models Developed:**
1. Logistic Regression - Predicts home team win probability
2. Ridge Regression - Predicts point margin (L2 regularization)
3. LASSO Regression - Predicts point margin with feature selection (L1 regularization)

**Key Outputs:**
- Model performance metrics (accuracy, ROC AUC, MAE, RMSE, R²)
- Home-field advantage quantification (win probability boost and point margin)
- Feature importance analysis
- Ridge vs. LASSO comparison

**Status:** ✅ Complete - Development phase finished

## Reproducibility Notes

### Running the Notebooks

**Environment Setup:**
```bash
# Install dependencies
pip install -r ../requirements.txt

# Start Jupyter
jupyter notebook
```

**Execution Order:**
1. Ensure data has been cleaned first (run data processing pipeline)
2. Open `model_home_field_advantage.ipynb`
3. Run all cells in order (Runtime > Run All)

**Dependencies:**
- Python 3.8+
- pandas
- numpy
- scikit-learn
- joblib
- jupyter

### Reproducibility Considerations

✅ **What Makes These Notebooks Reproducible:**
- Fixed random seeds (`RANDOM_STATE = 42`)
- Explicit train/test splits with consistent parameters
- Version-controlled hyperparameter grids
- Documented data preprocessing steps
- Clear dependency specifications

⚠️ **Limitations:**
- Interactive exploration may have been done in non-sequential cell execution
- Some cells may have been re-run during development
- Notebook state depends on execution order

### Transition to Production

The exploratory work in these notebooks has been **consolidated and refactored** into the production pipeline:
- `src/` - Modular, testable Python scripts
- `run_all.py` or `Makefile` - Orchestrates the full workflow
- Notebooks preserved for documentation and reference

**Why separate development from production?**
- **Notebooks:** Great for exploration, visualization, iteration
- **Scripts:** Better for automation, testing, deployment, reproducibility
